## Description (4000)
つらかった数週間をぼんやり思い出すのではなく、記録をもとに受診しましょう。

Tidemarkは、プレ更年期・更年期の症状を毎日シンプルに記録し、医師に見せられる1ページのまとめにするアプリです。

30秒で記録
• 自分で選んだ最大8つの症状を「なし・軽い・中くらい・強い」で評価
• 症状が生活にどれだけ影響したか、出血、ストレスやお酒、睡眠不足などの要因をメモ
• ほてりや寝汗はワンタップで記録。ロック画面のウィジェットからも記録できます
• 記録を忘れた日は、過去3日分まで入力できます

自分の傾向がわかる
• 4週・8週・12週の症状を日ごとに表示するグラフ
• 生理と不正出血の日がわかる周期カレンダー
• お酒や睡眠不足のあとに症状が出た回数（回数のみ）
• 薬やサプリメントを始める前と後の数値
• 毎週日曜日に短い週間まとめ

受診の準備
• 1ページのレポート：主な症状、出た頻度、Menopause Rating Scaleのスコア、周期、薬、聞きたいこと
• 印刷、メール送信、医療機関のポータルへのアップロードにそのまま使えます
• 受診後には、決まったことと次回の予定をメモ

データはあなたのもの
• iPhoneに保存され、あなた自身のiCloudに暗号化してバックアップ。私たちが見ることはありません
• アカウント不要、広告なし、データ販売なし
• いつでも全データをファイルに書き出し、読み込み直せます
• 削除した日は「最近削除した項目」に30日間残ります
• Face IDでのロックとAppleヘルスケアとの連携（任意）

無料とサブスクリプション
毎日の記録、履歴、傾向、バックアップ、書き出し、画面でのレポート表示は無料です。月額または年額のサブスクリプションで、印刷や送信に使えるPDFレポートが利用できます（価格は国によって異なります）。お支払いはApple IDに請求され、期間終了の24時間前までに解約しない限り自動更新されます。管理・解約はApple IDの設定から行えます。

Tidemarkはあなたが入力した内容を記録するアプリです。診断、治療の提案、医学的な助言は行いません。気になる症状がある場合は医師にご相談ください。
