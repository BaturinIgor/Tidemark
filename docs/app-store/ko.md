## Description (4000)
힘들었던 몇 주를 어렴풋이 떠올리는 대신, 기록을 들고 진료에 가세요.

Tidemark는 폐경 전후의 갱년기 증상을 매일 간단히 기록하고, 의사에게 보여 줄 수 있는 한 장짜리 요약으로 만들어 줘요.

30초 기록
• 직접 고른 증상 최대 8개를 없음, 약함, 중간, 심함으로 평가
• 증상이 하루에 얼마나 지장을 줬는지, 출혈, 스트레스나 술, 수면 부족 같은 요인을 메모
• 안면홍조나 식은땀은 한 번만 탭해서 기록. 잠금 화면 위젯에서도 가능해요
• 하루를 놓쳤나요? 최근 3일을 채울 수 있어요

나만의 패턴
• 4주, 8주, 12주 동안의 증상을 날짜별로 보여 주는 차트
• 생리일과 소량 출혈일을 보여 주는 주기 달력
• 술이나 수면 부족 뒤에 증상이 나타난 횟수(횟수만 표시)
• 약이나 보충제를 시작하기 전과 후의 숫자
• 매주 일요일 짧은 주간 요약

진료 준비 완료
• 한 장짜리 리포트: 주요 증상, 나타난 빈도, Menopause Rating Scale 점수, 주기, 약, 묻고 싶은 질문
• 인쇄, 이메일 전송, 병원 포털 업로드에 바로 사용
• 진료 후에는 결정된 내용과 재진 일정을 메모

내 데이터는 내 것
• iPhone에 저장되고 내 iCloud에 암호화되어 백업돼요. 저희는 절대 볼 수 없어요
• 계정 없음, 광고 없음, 데이터 판매 없음
• 언제든 모든 데이터를 파일로 내보내고 다시 가져올 수 있어요
• 삭제한 날은 최근 삭제된 항목에 30일 동안 남아요
• Face ID 잠금과 건강 앱 연동(선택)

무료와 구독
매일 기록, 기록 내역, 패턴, 백업, 내보내기, 화면 속 리포트는 무료예요. 월간 또는 연간 구독으로 인쇄하거나 보낼 수 있는 PDF 리포트를 이용할 수 있어요(가격은 국가마다 달라요). 결제는 Apple ID로 청구되며, 기간 종료 최소 24시간 전에 해지하지 않으면 자동으로 갱신돼요. Apple ID 설정에서 관리하거나 해지할 수 있어요.

Tidemark는 입력한 내용을 기록해요. 진단하거나 치료를 제안하거나 의학적 조언을 하지 않아요. 걱정되는 증상이 있다면 의사와 상담하세요.
