# Trademark knockout search: TIDEMARK

Date of search: 26 November 2026
Marks searched: TIDEMARK, TIDE MARK, TIDEMARKS, TIDEMARQ (phonetic variant), "Tidemark: Menopause Tracker"
Product: iPhone app, a perimenopause symptom tracker that builds a report for the user's doctor, sold by subscription
Classes of interest: 9 (downloadable software), 42 (SaaS), 44 (health information); 35/41 noted only where relevant
Markets: US and UK first, EU later

> **This is a preliminary knockout search, not legal clearance.** It used public web tools only. Several official registers (UKIPO, EUIPO, TMview, WIPO) could not be read by automated tools, so UK and EU coverage is incomplete. Before filing, or before spending on brand assets, run the manual queries below. For a final opinion, get a full clearance search from a trademark attorney.

## Recommendation

1. **US: file now with USPTO (TEAS),** standard character mark **TIDEMARK** (word only, no logo, no "Menopause Tracker", because that part is descriptive and would be disclaimed).
   - **Class 9:** downloadable mobile application software for tracking and recording menstrual, perimenopause and menopause symptoms and generating reports of the user's own data. Use USPTO ID Manual wording where you can.
   - **Class 42:** providing temporary use of online non-downloadable software for the same purpose. File this only if a web or cloud component is planned. An on-device iPhone app needs only class 9.
   - **Class 44:** optional. Its health-information wording ("providing information about health...") sits closest to the Tidemark therapy practices and adds cost without protecting the core product much. Recommended: 9 (+42 if a service component exists).
   - Basis: use in commerce if the app is live in the US; otherwise intent-to-use (1(b)), which adds a fee for the allegation of use later.
   - **Fees** (USPTO, checked on [uspto.gov "How much does it cost"](https://www.uspto.gov/trademarks/basics/how-much-does-it-cost)): **$350 per class** base fee. Surcharges apply per class: +$100 for insufficient information, and +$200 for free-form goods text not taken from the ID Manual (per USPTO's [additional fees page](https://www.uspto.gov/trademarks/additional-fees-trademark-applications)). One class: about $350; two classes: about $700. Check ITU statement-of-use and extension fees on the [fee information page](https://www.uspto.gov/trademarks/trademark-fee-information); this search could not fetch that page.
   - Risk to watch: a possible opposition by insightsoftware. The dead registration cannot be cited by an examiner, but the live common-law use can be raised in an opposition. Keep the description narrowly about consumer health tracking to strengthen the "unrelated goods" position.

2. **UK: run the UKIPO manual search first.** If it is clean, file with UKIPO online in **class 9** (+42 if needed). **Fees** from 1 April 2026: **£205** online for the first class, **£60** for each additional class (UK IPO [fee announcement](https://www.gov.uk/government/news/intellectual-property-office-fees-to-increase-from-april-2026) confirms £170 to £205; the £60 additional-class figure is from [CITMA](https://www.citma.org.uk/resources/uk-ipo-announces-first-trade-mark-fee-increase-in-nearly-three-decades-mb25.html) and law-firm summaries; confirm on the UKIPO fees table). One class: £205; two classes: £265.

3. **EU (later):** an EUTM online costs about **€850** for one class, +€50 for the second and +€150 for each class after that (secondary sources; the EUIPO fee page could not be fetched, so verify there). You can file a US or UK application first and claim priority within 6 months, or extend later through Madrid.

4. **Before launch:** check the App Store and Play Store by hand, and check the domain and social handles. tidemark.com belongs to insightsoftware, so plan on a domain like tidemark.app or a "tidemark" plus "health"/"meno" variant.

Fallback names: not needed. No hit reached high risk.

## Limits of this search

- Covers exact and close spellings only. It does not fully cover phonetic or translated equivalents, design marks, or state registrations.
- Trademarkia and web-search results can lag the official registers. Live USPTO statuses were confirmed on TSDR only for SN 85409860, 75569259, 99890929 and 99851587.
- UK, EU and WIPO registers were not read directly (see the manual queries above).
- Not legal advice. Talk to a trademark attorney before filing if insightsoftware's EU or UK position turns out to be a registered mark in class 9 or 42.
